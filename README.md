# MePIPE

Независимый Android-клиент для поиска и просмотра публичных видео YouTube. Интерфейс написан на Kotlin и Jetpack Compose с Material 3; поиск и получение потоков выполняются через NewPipe Extractor, воспроизведение — через ExoPlayer.

> MePIPE не связан с NewPipe e.V. или YouTube и не использует официальный YouTube Data API. Доступность YouTube и извлечения потоков зависит от сети и региона; изменения YouTube могут временно нарушить работу.

## Возможности alpha.2b

Это повторная сборка alpha.2 для решения проблемы с установкой и подготовки Android/F-Droid APK; функциональность поиска и воспроизведения не менялась.

- Поиск реальных публичных видео YouTube без API-ключа и входа в аккаунт.
- Превью, названия, каналы, длительность и доступные сведения о просмотрах/дате.
- Получение совместимого видеопотока и воспроизведение внутри приложения.
- Четыре сохраняемые цветовые схемы Material 3: Plant Life, Шалфей, Цитрус и Бирюза.
- Светлая и тёмная темы, загрузочные состояния и повтор запроса при сетевой ошибке.

## Известные ограничения

Это ранняя альфа. Пока нет входа в аккаунт, персональной домашней ленты, подписок, плейлистов, офлайн-загрузок, фонового воспроизведения и локальной истории. Главная показывает результаты запроса «популярное», а не персональные рекомендации YouTube.

## План следующей версии

- Отдельная вертикальная лента Shorts.
- Рабочая библиотека каналов и подписок, локальная история и сохранённые видео.
- Исследование безопасной интеграции аккаунта и синхронизации подписок.

Google-подписки требуют официальной OAuth-интеграции YouTube API и регистрации приложения. Встраивать запрос пароля Google или обходить авторизацию не будем; если официальный доступ недоступен, сделаем локальные подписки без входа в аккаунт.

## Сборка

Нужны JDK 17 и Android SDK Platform 35. Проект не зависит от Google Mobile Services, Firebase или Google Play Services. Информация о подготовке к F-Droid и ограничениях публикации: [`FDROID.md`](FDROID.md).

```bash
./gradlew assembleDebug
```

Debug APK появится по пути `app/build/outputs/apk/debug/app-debug.apk`, unsigned F-Droid APK — в `app/build/outputs/apk/release/app-release-unsigned.apk`. GitHub Actions проверяет подпись debug APK и собирает обе версии.

## Установка alpha.2b

Для ручной установки скачайте [подписанный debug APK из релиза alpha.2b](https://github.com/avasil307-design/MePIPE-yt/releases/download/v0.1.0-alpha.2b/mepipe-v0.1.0-alpha.2b-debug.apk). Это тестовая сборка, не production-релиз. Если на устройстве установлена другая MePIPE debug-сборка, сначала удалите её: debug-сертификаты разных CI-запусков могут отличаться. APK с `fdroid-unsigned` в названии не устанавливается напрямую — F-Droid подпишет свою сборку.
