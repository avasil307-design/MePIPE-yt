# MePIPE

Независимый Android-клиент для поиска и просмотра публичных видео YouTube. Интерфейс написан на Kotlin и Jetpack Compose с Material 3; поиск и получение потоков выполняются через NewPipe Extractor, воспроизведение — через ExoPlayer.

> MePIPE не связан с NewPipe e.V. или YouTube и не использует официальный YouTube Data API для поиска видео. Доступность YouTube и извлечения потоков зависит от сети и региона; изменения YouTube могут временно нарушить работу.

## Возможности 0.2.0-alpha.2

- Поиск публичных видео YouTube без API-ключа и входа в аккаунт.
- Превью, названия, каналы, длительность и доступные сведения о просмотрах/дате.
- Получение совместимого видеопотока с ограничением времени; ошибки извлечения и ошибки ExoPlayer показываются отдельно. Alpha.2 дополнительно показывает последний HTTP endpoint и время ответа/тайм-аута.
- Локальные тематические рекомендации из успешно использованных поисковых запросов; их можно очистить в разделе «Вы».
- Экспериментальный вход в Google через системный браузер с PKCE и получение подписок YouTube через официальный Data API (требуется собственный совместимый OAuth Client ID; см. [`OAUTH_SETUP.md`](OAUTH_SETUP.md)).
- Четыре сохраняемые цветовые схемы Material 3: Plant Life, Шалфей, Цитрус и Бирюза.
- Светлая и тёмная темы, загрузочные состояния и повтор запроса при сетевой ошибке.

## Важно для тестирования

Сборки 0.2.0-alpha добавляют тайм-ауты и диагностику, но это само по себе не подтверждает исправление воспроизведения. Alpha.2 показывает endpoint последнего запроса при тайм-ауте, чтобы локализовать сетевую причину. Нужны фактические проверки на устройстве: поиск, получение ссылки на поток, запуск/просмотр видео и поведение при VPN/ошибке сети. Google OAuth и загрузка подписок также пока не прошли проверку живой конфигурацией.

Рекомендации на главной — локальные тематические подсказки по успешным запросам, а не персональная лента YouTube. Подписки Google используются для показа списка подписанных каналов; персональная видео-лента по подпискам пока не реализована.

## Google OAuth и F-Droid

Google-вход открывается во внешнем системном браузере, а не во встроенном WebView. MePIPE не запрашивает пароль Google, не встраивает клиентский секрет и не зависит от Google Play Services. Refresh token хранится в зашифрованном виде с ключом Android Keystore. Инструкция по OAuth и ограничениям конфигурации: [`OAUTH_SETUP.md`](OAUTH_SETUP.md).

В проекте нет GMS, Firebase или Play Services. F-Droid-сборка не содержит OAuth-секретов; пользователь должен предоставить собственный совместимый публичный OAuth Client ID для использования Google-подписок. Подробнее о сборке и статусе F-Droid: [`FDROID.md`](FDROID.md).

## Сборка

Нужны JDK 17 и Android SDK Platform 35.

```bash
./gradlew :app:verifyFdroidRuntimeDependencies :app:assembleDebug :app:assembleRelease
```

Debug APK появится по пути `app/build/outputs/apk/debug/app-debug.apk`, unsigned F-Droid APK — в `app/build/outputs/apk/release/app-release-unsigned.apk`. GitHub Actions проверяет сборку, подпись debug APK и отсутствие GMS/Firebase/Google Play SDKs в runtime dependency graph.

## Установка

Для ручной установки используйте подписанный debug APK из GitHub Release, а не APK с суффиксом `fdroid-unsigned`. Если на устройстве установлена другая MePIPE debug-сборка, сначала удалите её: debug-сертификаты разных CI-запусков могут отличаться.
